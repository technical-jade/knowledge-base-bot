# Описание бота (для вопросов «как тебя использовать»)

Бот @jade_kb_bot — личный помощник для базы знаний
`https://jade.tail2b43aa.ts.net/kb/` (сайт открывается только в тайлнете).

Что умеет:

- **Писать статьи.** «Напиши гайд по Docker volumes», «В DevOps: статья про
  nginx», «Сделай учебник по Rust из 4 глав». Если стиль не указан, бот
  покажет кнопки: «Простыми словами», «Разработчику, с нуля в теме»,
  «Справочник/шпаргалка», «Учебник из глав» (без выбора за 10 минут —
  «Разработчику»). Через несколько минут — ссылка на опубликованную статью.
- **Править.** «Добавь пример с compose» — правится текущая (последняя)
  статья; ответ (Reply) на сообщение бота со ссылкой — правится эта
  статья; «В статье про Git rebase поправь…» — названная. Правка помнит
  разговор о статье: «сделай короче», «верни как было в третьем разделе».
  «Перенеси в Frontend» — перенос в другой раздел.
- **Отвечать на вопросы** с поиском в интернете — как обычный чат, с памятью
  разговора. «Сделай из этого статью» — статья из текущего разговора.
- **Искать по базе:** «что у меня есть про сети?», «что я записывал о
  volumes?».

Команды:

- `/new <тема>` — новая статья
- `/ask <вопрос>` — ответ по статьям базы со ссылками
- `/find <запрос>` — найти статьи
- `/list` — разделы и статьи с кнопками
- `/recent` — последние изменения (кнопка ↩️ — отменить последнее)
- `/delete <что>` — удалить статью, учебник или раздел целиком (с подтверждением): «/delete раздел Frontend»
- `/undo` — отменить последнее изменение бота (с подтверждением)
- `/deploy` — опубликовать ручные правки из git
- `/reset` — начать новый разговор
- `/help` — справка

Кнопки:

- `/list` → раздел → у каждой статьи ✏️ (править: бот спросит, что
  изменить, — ответьте на его сообщение) и 🗑 (удалить с подтверждением);
  нажатие на название — карточка статьи: 🌐 открыть, 🔀 перенести,
  быстрые правки ✨ Короче, 🧒 Проще, ➕ Примеры, 🔄 Факты (проверка
  актуальности). «➕ Новая» в разделе — статья сразу в этот раздел.
- Под «Готово: ссылка» — 🌐 ✏️ 🔀 ↩️ 🗑.
- На сообщении «⏳ …» — ✖️ Остановить: задача прерывается, изменения
  откатываются (кроме момента публикации).
- Под ответом на поиск — кнопки найденных статей.

Ручная правка: `git clone git@github.com:technical-jade/knowledge-base.git`
→ правка в `docs/` → `git push` → боту `/deploy`.

Правило: **секреты (пароли, токены, рабочие данные) в базу не класть.**
